CC_Codex 二期（26.11）**数据工程**产品线：**抓取隔离舱检疫台**（Pyramid + Waitress + 原生 JS SPA 右侧抽屉 + SQLite）。

## 一句话骨架

**抓取批次 → 坏件入隔离舱 → 复核放行 / 回炉重抓 → 隔离对账**

与血缘影响、压实合并、回灌切片、契约换版、水印盖印、清单闭合、留存裁撤**正交**；不做 CDC 游标 / Feed 归并 / Slicegate 类指纹。

## 入舱落点（旁路凭证表，唯一选边）

入舱落点只兑现一边：**旁路凭证表 `entry_vouchers`**，不与物化文件并开。

- 入舱整笔事务（`BEGIN IMMEDIATE` + 进程内互斥锁），锁写入舱瞬间的条目键、载荷、质量标记、来源与样本指纹（SHA-256），凭证表只 INSERT/SELECT，无 UPDATE 入口，拒改写。
- 隔离舱卡片与舱内行、复核详情一律读凭证快照，不再回读 `capture_items` 现行值，避免漂件污染；页面亮来源芯片与坏件计数。
- 样本指纹与舱内凭证拧花（或缺凭证）时，复核继续与清洗入库/回炉统一拦截，返回中文短句。
- 两人争抢同一坏件：互斥 + `UNIQUE(item_id)`/`UNIQUE(row_id)` 兜底，恰好一边兑现，舱行与凭证各一份。
- 台参数页 `entry_landing_mode` 为只读口径项，强改返回中文错误。
- 历史舱行在启动时幂等补凭证；对账报告含「缺凭证」错位口径。
